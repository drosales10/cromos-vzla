# Documentacion del Proyecto

Este directorio concentra la documentacion funcional y tecnica del proyecto Cromos Panini.

## Contenido

- [estado-tecnico.md](estado-tecnico.md): estado actual de arquitectura, stack y decisiones de base de datos.
- [plan-fases.md](plan-fases.md): plan de evolucion por fases para sobres, economia y trueques.
- [manual-uso.md](manual-uso.md): manual de uso de la aplicacion para usuarios finales.
- [superusuario-imagenes.md](superusuario-imagenes.md): operacion de superusuario, gestion del pool de barajitas y carga de imagenes.
- [api-cromos.md](api-cromos.md): contrato vigente de cromos basado en inventario por cantidades y deprecacion de campos legacy.

## Nota

La informacion fue consolidada de las notas de memoria del repositorio y de la sesion de trabajo para dejar una referencia coherente en el codigo fuente.
